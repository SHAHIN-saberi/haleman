# پلن پیشبرد کار — چت‌بات دستیار روانشناختی

**تاریخ شروع:** ۱ مهر ۱۴۰۵ (۲۳ سپتامبر ۲۰۲۶)
**مبنا:** درس Beyond Prototype (ساخت تا لانچ و انتشار) + تمرین فرضیه مسئله و تحقیقات کاربر + مدل ۴ ریسک محصول + فانل آگاهی

## قانون همکاری (توافق‌شده)

1. هر مرحله فقط با تایید تو بسته می‌شود و بعد می‌رویم مرحله بعد.
2. هر جا اطلاعات یا نظر تو لازم باشد، می‌پرسم؛ از خودم حدس و پیش‌فرض پر نمی‌کنم.
3. تصمیم‌های باز در «دفتر تصمیم‌ها» ثبت می‌شود تا چیزی گم نشود.

## جزئیات هر مرحله

**مرحله ۱ — تکمیل Problem Test:** مصاحبه‌های ۸ تا ۱۲ نفره طبق راهنمای داخل فایل تمرین انجام می‌شود و جدول یافته‌ها پر می‌شود؛ پرسشنامه هم روی حداقل ۱۰۰ نفر اجرا می‌شود. معیار بسته شدن: جدول یافته‌ها پر + جمع‌بندی الگوها نوشته شده.

**مرحله ۲ — BRD:** ورودی‌اش نتایج مرحله ۱ + تصمیم‌های D1 تا D4 است. معیار بسته شدن: تایید تو روی اسکوپ (چه چیزی هست / چه چیزی نیست)، بنچمارک‌ها و پلتفرم. مدل درآمدی معوق — اولویت دوم.

**مرحله ۳ — ریسک‌ها + تعریف MVP Test:** طبق درس جدید ما Bottom-Up هستیم پس MVP ما «آزمایش فرضیه» است نه محصول کامل. برای هر ۴ ریسک یک آزمایش ارزان تعریف می‌کنیم. معیار بسته شدن: تایید تو روی لیست آزمایش‌ها و معیار عبور هر کدام.

**مرحله ۴ — PRD:** فقط برای اسکوپ تاییدشده مرحله ۲. معیار بسته شدن: تایید تو روی سفر کاربر و یوزر استوری‌ها.

**مرحله ۵ — وایرفریم:** فقط برای صفحات داخل PRD. معیار بسته شدن: تایید تو روی فلو و صفحات.

**مرحله ۶ — تصمیم فنی + بیلد:** انتخاب مدل (اوپن‌سورس / بسته) و ابزار ساخت (کدنویسی / وایب‌کدینگ) بر اساس محدودیت‌های تو + ملاحظه حریم خصوصی داده سلامت. معیار بسته شدن: نمونه اولیه‌ای که سناریوی PRD را اجرا کند.

**مرحله ۷ — تست + دیپلوی و لانچ:** تست با ۵ تا ۱۰ کاربر واقعی + تست اجباری پروتکل بحران (خودکشی/خودآزاری) + انتخاب محل دیپلوی (داخل / خارج) + پیام لانچ متناسب با سطح آگاهی مخاطب در فانل. معیار بسته شدن: انتشار + اولین کاربرهای واقعی.
