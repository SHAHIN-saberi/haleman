**F-2 (root cause + fix, measured on the same button)** — `reports/senior/t003b-f2-timeline.json`:

```
fixed build   transition-property: background-color, color
              focus → rgb(61,90,128) at once, stays (no faded-in ring)
old rule      transition-property: … outline-color …
              focus+0ms → rgb(245,242,234)  (= label colour = page bg → invisible)
              focus+30ms → rgb(213,216,216) · focus+80ms → rgb(91,115,145)
              focus+140ms → rgb(62,91,129) · focus+440ms → rgb(61,90,128) settled
```

So Tailwind v4's colour utility does animate `outline-color` ≈6× longer than the state change; the fix removes that
property from the list. The built CSS now contains only `transition-property: background-color, color` and
`transition-property: color` — no `outline-color` anywhere.

## Deviations / decisions worth a look

- **D-1 `/terms` copy.** Implemented the plan-gate-approved copy (heading + the three W-02 lines + «متن کامل پس از
  تأیید حقوقی منتشر میشود.»), which supersedes the older one-liner («متن نهایی بهزودی») in `M1-orders-1.md`
  §T-003B-1. No legal sentence is invented; the page stays a stub until Q-08.
- **D-2 Title placement.** The wireframe draws a per-screen `.pbar` (13.5 px bold, card bg). In this build that bar
  role is already played by the shared `AppHeader`, so each screen keeps its own title in the body as an H2 (17 px,
  design-system type scale). Copy is unchanged; only the size/placement differs from the wireframe crop.

  `[background-color,color]` — nothing in the app changes a border colour on hover, so animating it would only be
  dead weight. Hover feedback is unchanged.

  W-10 overlay (empathy card, flow pause, ghost «حالا امنم، ادامه میدهم») is T-015, and it will replace this bar.
- **D-5 `/terms` is a dead end in M1** (no in-page control; browser back is the way out). Deliberate: the order says
  "heading only", and inventing a navigation label would be new copy. The real page arrives with Q-08.
- **D-6 Harness data.** The probe runs real flows against the dev database, so it accumulated rows (41 identities /
  5 consent rows). Dev DB only; nothing in the repo or the production path depends on it.
- Also recorded in code: Tailwind v4 scans **comments** for class names — writing the old utility's name in prose made
  the compiler emit exactly the rule the fix removes. `Button.tsx` now says it in words.
